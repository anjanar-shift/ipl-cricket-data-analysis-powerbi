# ipl-cricket-data-analysis-powerbi
Power BI dashboard analyzing IPL cricket data - batting, bowling, and team performance insights
## Data Source
The dataset used for this analysis was sourced from Kaggle (IPL Ball-by-Ball and Match dataset).

## Tools Used
- Power BI
- Data Visualization (Cards, Bar Charts, Line Charts, Pie Charts)
- Interactive Filters & Slicers

## Key Insights
- Total matches, venues, and seasons analyzed (2008–2024)
- Team-wise win analysis across all seasons
- Season-wise run trends over the years
- Toss effect on match outcomes
- Top venues by matches hosted
